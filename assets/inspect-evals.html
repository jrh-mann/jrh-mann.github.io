Questions

FAQ

What is Inspect AI?
An open-source evaluation framework created by JJ Allaire (founder of RStudio). It gives governments, industry, and academia a common framework for developing and running agentic evaluations.
Do the Inspect Evals team need to be cited?
Co-authorship is not a requirement. For academic integrity, we advise listing Inspect Evals in the acknowledgements — especially if compute credits produce results for the paper. A mention in the methodology section is appreciated.
Who owns the code?
Licensing and intellectual property remain with the original authors. Authorship is cited within the benchmark's README.
What if my benchmark is private?
For private benchmarks or those with embargo dates, we can arrange confidentiality agreements and modify our processes to align with your infosecurity requirements.
What if I disagree with the maintainers?
If the disagreement is about capacity, we take on additional work if justified. For best-practice differences, we accommodate both approaches where possible — for example, via a parameter. The only hard requirements are security requirements for organisational users.
What if my plans change?
If there are significant deviations from the agreed scope, involvement is reviewed. Adjustments are agreed mutually — for example, a position in the next cohort if unexpected delays occur.
